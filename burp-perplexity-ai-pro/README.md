# Burp Perplexity AI Pro Extension

Advanced AI-powered security testing extension that replicates native Burp AI functionality using Perplexity AI.

## Features

✅ **Active Vulnerability Testing**
- Automated payload generation and testing
- Multi-step analysis with AI reasoning
- Real-time vulnerability detection

✅ **Task Management System**
- Track all testing activities
- Step-by-step execution logging
- Credit usage monitoring

✅ **Comprehensive Test Types**
- SQL Injection
- Cross-Site Scripting (XSS)
- Command Injection
- Path Traversal
- XXE, SSRF, CSRF
- Authentication/Authorization Bypass
- Full vulnerability scans

✅ **Burp Integration**
- Context menu in Repeater
- Send results to Repeater/Intruder
- Task dashboard
- AI testing panel
